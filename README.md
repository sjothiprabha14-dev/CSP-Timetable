# CSP Timetable Scheduling

A simple **Constraint Satisfaction Problem (CSP)** implemented in Python using **Backtracking**.

### Features

* Subjects as variables
* Time slots as domains
* Constraints between subjects
* Backtracking search
* Displays the final timetable

### Technologies

* Python
* CSP
* Backtracking

### Run

```bash
python task3.py
```
